## 程序简介

Automated Player Skin Acquisition Tool(下文简写为Apsat) 是一款用于保存 Minecraft 玩家 (包括 Microsoft账户 与 第三方Yggdrasil账户) 档案下的自定义皮肤、披风与完整档案的GUI工具

其余请见 [帮助界面](https://deswatts.github.io/DeswattsDocs)
